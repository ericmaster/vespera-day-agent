Event model

{ id, ts, source_id, context, action, text, lines?, review_seconds?, review_comments?, files_viewed?, review?, trigger?, assigned_by?, approved_via? }
Actions: session_started, pr_opened, review_requested, ping, work, approved, ci_run, ci_failed, closed, anchor_start. Triggers: ai_remark, mention, self. Fixture and live GitHub events share this shape, so detectors run unchanged on both.
