Review quality, evidenced.

It doesn't measure your hours, it measures whether you got to review.

What it is. A developer-owned agent. From sources you grant (chat, email, coding-agent sessions, GitHub PRs/commits, calendar, tasks) it builds a context-switch timeline and tracks one number: items closed with proper review. Two deterministic detectors (task drift, rubber-stamp review) feed a Meta Muse Spark agent that proposes alerts, parked side-quests, verification checklists, no-interrupt review blocks and team status drafts. A deterministic validator checks every proposal; you approve each one. Nothing is sent. There is no manager view.

Resumen para Eric (ES)
  • Ancla: la tarea asignada con su evidencia (issue asignado, pedido en chat).
  • Desvío (drift): un disparador (comentario de la IA, mención o hallazgo propio) te lleva a otro contexto ≥ 15 min antes de volver al ancla.
  • Rubber stamp: algo quedó "revisado" sin evidencia: aprobado muy rápido para su tamaño, sin CI, la IA dijo "tests pass" sin log, o 0 comentarios y 0 archivos vistos.
  • Validador: código determinista; rechaza números o citas que no cuadran con la evidencia. Muse Spark solo redacta y propone.
  • Fallback offline: si la API falla, corre un agente guionado por el mismo validador y la UI lo marca.
